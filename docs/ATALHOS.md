# Atalhos

`Super` é a tecla Windows. Os atalhos seguem os hábitos do original quando o
modelo Wayland permite. `local.lua` pode substituí-los com `hl.unbind`/`hl.bind`.

| Teclas | Ação |
|---|---|
| Super + Enter | Terminal integrado |
| Super + Alt + Enter | Terminal flutuante |
| Super + Espaço | Launcher de aplicativos |
| Alt + Espaço | Seletor dos 18 temas, com prévias |
| Super + Alt + W | Wallpapers do tema e diretório local |
| Super + R | Editor de borda, raio, blur, sombras, animações e opacidade |
| Super + F / B / P | Arquivos / navegador / mixer |
| Super + X | Fechar janela |
| Super + setas | Mover foco |
| Super + Shift + setas | Mover janela |
| Super + 1…9 | Trocar workspace |
| Super + Shift + 1…9 | Enviar janela ao workspace |
| Super + Shift + Espaço | Alternar flutuante |
| Super + F11 / M | Tela cheia / maximizar |
| Super + clique esquerdo / direito arrastando | Mover / redimensionar |
| Super + vírgula / ponto | Monitor anterior / seguinte |
| Super + Shift + vírgula / ponto | Enviar janela a outro monitor |
| Super + Alt + O | Scratchpad no workspace especial |
| Alt + Tab | Seletor de janelas via IPC Hyprland |
| Super + Alt + N / B | Rede / Bluetooth |
| Super + Alt + C | Clipboard |
| Super + Alt + K | Próximo layout de teclado configurado |
| Super + Alt + L | Estilo do launcher: normal, tela inteira, mínimo |
| Print / Shift + Print / Alt + Print | Captura completa / região / janela focada |
| Super + Alt + S | Menu de captura |
| Super + Ctrl + L | Bloquear |
| Super + Alt + P | Menu bloquear, suspender, sair, reiniciar, desligar |
| Ctrl + Super + Alt + P / R / Q | Desligar / reiniciar / sair, com confirmação |
| Super + Alt + H / U | Ocultar / mostrar barras |
| Super + Alt + R | Reaplicar tema e consultar monitores |
| Alt + F1 | Este guia na interface |
| Teclas de volume / microfone / brilho / mídia | Dispositivos padrão detectados |

O aplicativo Rofi pode ser cancelado com Escape. Ações de energia destrutivas
sempre apresentam uma segunda escolha, inicialmente em **Cancelar**. O atalho
de encerramento forçado por SIGKILL do upstream não é reproduzido.
